# Airline Passenger Satisfaction Analysis

## Project Overview

This project analyzes airline passenger satisfaction using Python and Machine Learning. It explores passenger data to identify patterns related to satisfaction and builds classification models to predict whether passengers are satisfied or neutral/dissatisfied.

## Objectives

* Clean and preprocess the dataset for machine learning.
* Build and evaluate classification models.
* Compare Logistic Regression and Random Forest performance.

## Tools & Technologies

* **Programming:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Machine Learning Models

* Logistic Regression
* Random Forest Classifier

## Results

* **Logistic Regression Test Accuracy:** 87.4%
* **Random Forest Test Accuracy:** 95.7%
* **Random Forest Training Accuracy:** 96.6%

## Project Structure

* `AirlineSatisfaction_ML.ipynb` — Notebook containing data analysis, preprocessing, model training, and evaluation.
* `Airline_Satisfaction_Cleaned.csv` — Cleaned dataset used for analysis.

## Key Areas

Data Analysis, Data Cleaning, Exploratory Data Analysis, Data Visualization, Classification, and Model Evaluation.
